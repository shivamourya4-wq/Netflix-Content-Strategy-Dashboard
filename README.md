# Netflix Content Strategy Dashboard

## About the Project

This project is about analyzing the Netflix Movies and TV Shows dataset. The data was cleaned in Excel, analyzed using MySQL, and visualized in Power BI.

The goal of this project is to understand Netflix's content library and find useful business insights.

---

## Project Objectives

The main objectives of this project are:

- Analyze Netflix movies and TV shows.
- Find the top content-producing countries.
- Identify the most popular genres.
- Analyze content ratings.
- Study content growth over the years.
- Build an interactive Power BI dashboard.

## Dataset

**Dataset Name:** Netflix Movies and TV Shows

**Source:** Kaggle

**File Format:** CSV

---

## Step 1: Data Cleaning (Excel)

The following cleaning steps were completed:

- Checked duplicate records (No duplicates found)
- Removed extra spaces
- Fixed incorrect column values
- Converted the `date_added` column to Date format
- Filled missing values in:
  - Director
  - Cast
  - Country
  - Rating
- Kept missing `date_added` values blank

---

## Step 2: SQL Analysis

The cleaned dataset was imported into MySQL.

The following analysis was performed:

- Total Movies and TV Shows
- Top 10 Countries
- Top Genres
- Rating Distribution
- Content Added by Year
- Director Analysis
- Content Growth Analysis

---

## Step 3: Power BI Dashboard

The dashboard contains:

- KPI Cards
- Top Genres
- Movies vs TV Shows
- Rating Distribution
- Top 10 Countries
- Content by Year and Type

## Key Insights

- Drama is one of the most popular genres.
- Netflix added more content after 2016.
